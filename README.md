# primitive_db

Простой CLI-инструмент для управления таблицами (метаданными) с сохранением в JSON-файл.


## Установка

Склонируйте репозиторий и установите зависимости:

```bash
uv sync
```

## Запуск

Из корня проекта:

```bash
uv run project
```


После запуска открывается интерактивный режим. Пользователю предлагается набор доступных команд.
Введите команду и нажмите Enter.
## Управление таблицами

Все операции выполняются в интерактивном режиме. Метаданные таблиц хранятся в файле `db_meta.json` в рабочей директории: он загружается при старте и сохраняется после каждой успешной операции `create_table` / `drop_table`.

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу с указанными столбцами |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `list_tables` | Показать список всех таблиц |
| `help` | Показать справку |
| `exit` | Выйти из программы |

### Поддерживаемые типы данных

- `int` — целое число
- `str` — строка
- `bool` — логическое значение

### Особенности

- Столбец `id` типа `int` добавляется автоматически в начало таблицы, если пользователь не указал его явно.
- Если пользователь указал `id` сам, его тип обязательно должен быть `int`.
- Имена столбцов внутри одной таблицы не должны повторяться.
- Имена таблиц и столбцов не должны быть пустыми.
- Неизвестные команды и некорректные значения не завершают программу — выводится сообщение и запрос повторяется.

## CRUD-операции

После создания таблицы с ней можно работать через команды insert, select, update, delete. Значения передаются в том порядке, в котором столбцы были объявлены при создании таблицы (без id — он генерируется автоматически).

### Команды

| Команда | Описание |
|---|---|
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | Добавить запись |
| `select from <имя_таблицы>` | Показать все записи таблицы |
| `select from <имя_таблицы> where <столбец> = <значение>` | Показать записи по условию |
| `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец> = <значение>` | Обновить записи по условию |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить записи по условию |
| `info <имя_таблицы>` | Вывести информацию о таблице |

### Правила ввода значений

- **Строковые значения** указывайте в кавычках:  `where name = 'John'`. Без кавычек строка не распознается — выводится сообщение `Строковые значения должны быть в кавычках: ...`
- **Числа **  - без кавычек: `where age = 30`
- **Логические значения** - `true` / `false` в любом регистре.
- В `insert`. значения перечисляются через запятую в скобках: `insert into users values (John, 30, true)`
- В `select` / `update` / `delete` условие — ровно одно, вида `<столбец> = <значение>`.

### Особенности

- `id` генерируется автоматически как `max(id) + 1` и в `insert` не передаётся.
- Количество значений в `insert` должно совпадать с числом столбцов таблицы без `id`.
- Типы значений проверяются по схеме таблицы: `int`, `str`, `bool`.
- Если таблица не найдена или значение некорректно, выводится сообщение, а программа продолжает работу.
- Результат `select` выводится в виде таблицы (`PrettyTable`); если записей нет — `Нет данных для отображения`.
